mini banking system project.

- Classes and Objects
- Constructors
- Instance Variables
- Encapsulation

- Class Methods

## Banking System

The banking system demonstrates:

- Bank account creation
- Customer details
- Deposit
- Withdrawal
- Balance checking
- Savings Account
- Current Account
- Current Account overdraft
- Encapsulation of account information
- Inheritance and method overriding
